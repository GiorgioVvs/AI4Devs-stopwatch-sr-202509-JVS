### **¿Qué chatbot(s) usaste?**
Utilicé **Copilot de Microsoft**.
### **¿Qué problemas encontraste al interactuar con el modelo?**
Algunos de los problemas fueron:
- A veces el modelo proponía soluciones demasiado genéricas que requerían ajustes para adaptarse al contexto específico del proyecto.
- En ciertas ocasiones, el modelo no interpretaba correctamente la intención detrás de una funcionalidad nueva sin una descripción muy detallada.
- Fue necesario reformular algunas instrucciones para obtener respuestas más precisas o técnicas.
### **¿Qué decisiones tuviste que tomar tú como desarrollador para mejorar el código propuesto?**
Tuve que tomar decisiones como:
- **Refinar la lógica de manejo de múltiples instancias** para evitar conflictos entre temporizadores y cronómetros.
- **Optimizar el uso de eventos y ciclos de vida** en el DOM para asegurar que los elementos se eliminaran correctamente sin dejar procesos activos.
- **Agregar validaciones** para mejorar la experiencia del usuario y evitar errores en la configuración de los temporizadores.
### **¿Cómo evaluarías la utilidad de este flujo de trabajo real?**
Evaluaría este flujo de trabajo como **muy útil**, especialmente para:
- **Prototipado rápido** de funcionalidades.
- **Documentación clara y estructurada** que facilita la colaboración.
- **Iteración eficiente** en el desarrollo de nuevas características. Sin embargo, requiere que el desarrollador tenga criterio técnico para revisar, adaptar y validar las propuestas del modelo antes de integrarlas al proyecto.
